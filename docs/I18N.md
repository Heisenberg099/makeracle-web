# English + Hindi

The header has a language switch (EN / हिंदी). The choice is saved in the visitor's browser.

**Today:** header and navigation strings are translated (`src/i18n/dictionaries.ts`). All page copy — every page, course and form — lives in one file, `src/content/en.ts`, so it can be translated in one place. To add Hindi page copy, copy it to `src/content/hi.ts` with the same keys and wire it up through locale routes (below).

## Translating more text

1. Add a key to both `en` and `hi` in `src/i18n/dictionaries.ts` (TypeScript will complain if one is missing from `en`).
2. In a client component: `const { t } = useLang();` then `t("your.key")`.
3. Server components can't read the visitor's choice yet. For long page copy, the planned approach is
   locale routes (`/hi/...`) — see the Next.js internationalization guide in
   `node_modules/next/dist/docs/01-app/02-guides/internationalization.md`. Agree this as a team before starting.

## Rules

- Code keywords and tool names stay in English (Python, HTML, Scratch).
- Have a native speaker review every Hindi string before launch.
- Later languages (Marathi, Tamil, Telugu, Bengali, Kannada) follow the same pattern.
